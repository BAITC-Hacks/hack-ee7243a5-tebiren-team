# Локальные проверочные профили

Войти как HR и импортировать оба файла вместе через Import data.

- E9001: низкий Public Speaking, три пропуска клуба и разрыв в критичном System Design. При выборе учитывать критичность и историю, а не только минимальный навык.
- E9002: Data Analyst Middle с целью Product Manager Middle; проверяет переход в другую роль.
- E9003: Lead без карьерной цели и без истории; ожидается пустой список шагов с причиной no_target.

Это производные синтетических профилей стартового набора, не реальные сотрудники и не скрытые профили жюри. Импорт повторных ID отклоняется. Reset demo data очищает все локальные импорты и симуляции; перед сбросом сохраните нужную БД.
